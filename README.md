# C-Aufgaben

Dieses Repository enthält Übungsaufgaben in der Programmiersprache C, die ich während meiner Umschulung bearbeitet habe. Sie dokumentieren meinen Lernfortschritt und die praktische Anwendung der Programmiergrundlagen.
 
Inhalt
 
Die Aufgaben behandeln unterschiedliche Problemstellungen und Lösungsansätze in C. Die jeweiligen Quelldateien enthalten meine Lösungen.
 
Technologien
 
- Programmiersprache C
- C-Compiler, beispielsweise GCC
 
Aufgaben ausführen
 
Zum Ausführen wird ein C-Compiler benötigt.
 
1. Das Repository herunterladen oder klonen.
2. Die gewünschte Aufgabe in einer geeigneten Entwicklungsumgebung öffnen.
3. Das Programm kompilieren und ausführen.
 
Eine einzelne Quelldatei lässt sich beispielsweise mit GCC kompilieren:
 
gcc aufgabe.c -o aufgabe
 
Je nach Aufgabe können mehrere Quelldateien oder zusätzliche Einstellungen erforderlich sein.
 
Lernziele
 
- Grundlagen der C-Programmierung festigen
- Programmierlogik und strukturiertes Denken üben
- Eigene Lösungsansätze entwickeln
- Fehler erkennen und beheben
 
Hinweis
 
Dieses Repository ist eine Sammlung von Lern- und Übungsaufgaben. Die Lösungen spiegeln meinen jeweiligen Kenntnisstand während der Umschulung wider.
